# 🗳️ Sistema de Votação em C (Simulador de Urna Eletrônica)

Projeto desenvolvido para fins de estudos e prática de conceitos fundamentais da linguagem C.

## 🚀 Status do Projeto
- [x] **Fase 1:** Lógica inicial básica (leitura e comparação simples)
- [ ] **Fase 2:** Contadores de votos e laço de repetição contínuo
- [ ] **Fase 3:** Confirmação de voto (Confirma / Corrige)
- [ ] **Fase 4:** Refatoração usando `struct` e vetores
- [ ] **Fase 5:** Emissão de Boletim de Urna com porcentagens

## 🛠️ Tecnologias Utilizadas
- Linguagem C
- Compilador GCC
